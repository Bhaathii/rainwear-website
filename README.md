# Rainwear (Pvt) Ltd - Corporate Website

A modern, professional, and mobile-responsive corporate website for Rainwear (Pvt) Ltd, Sri Lanka's leading waterproof garment manufacturer since 1989.

## 🌟 Features

- **Modern Design**: Clean, professional corporate design with smooth animations
- **Mobile Responsive**: Fully responsive across all devices and screen sizes
- **Fast Loading**: Optimized CSS and JavaScript for quick page loads
- **SEO Friendly**: Proper meta tags, semantic HTML, and structured content
- **Accessible**: Follows web accessibility best practices

## 📁 Project Structure

```
rainwear2/
├── css/
│   └── styles.css          # Main stylesheet
├── js/
│   └── main.js             # JavaScript functionality
├── images/                  # Image assets folder
├── index.html              # Home page
├── about.html              # About Us page
├── capabilities.html       # Manufacturing Capabilities page
├── news.html               # News & Updates page
├── compliance.html         # Compliance & Certifications page
├── contact.html            # Contact page
└── README.md               # This file
```

## 📄 Pages Overview

### 1. Home Page (index.html)
- Hero section with company highlights
- Features/Why Choose Us section
- Company overview
- Product categories
- Global footprint statistics
- Sustainability commitment
- Call-to-action section

### 2. About Page (about.html)
- Company history (since 1989)
- Mission & Vision statements
- Business overview
- Purpose & Values
- Awards & Achievements (Queen's Awards)
- Leadership team
- Quality & Ethical policies

### 3. Capabilities Page (capabilities.html)
- Tabbed interface for different capabilities:
  - Bulk Manufacturing (Storage, Cutting, Sewing, Production, Quality, Packing)
  - Design & Development (Tech Pack, Bonding, PUR, Fabric Sourcing, Costing, Supply Chain)
  - Technology (SDP System, Product Categories)
  - Fabric Types (Waterproof, Softshell, Travel, Heritage, Base Layer, Thermal)

### 4. News Page (news.html)
- Latest news and announcements
- Featured achievement section
- Newsletter subscription

### 5. Compliance Page (compliance.html)
- ISO 9001:2015 certification
- ISO 14001:2015 certification
- Health & Safety Policy
- Environmental Policy
- Ethical Policy
- Garments Without Guilt certification

### 6. Contact Page (contact.html)
- Contact form with validation
- Company contact information
- Product range overview
- Interactive Google Maps location
- Company particulars

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables, Flexbox, Grid
- **JavaScript**: Vanilla JS for interactivity
- **Font Awesome 6**: Icons
- **Google Fonts**: Poppins & Open Sans typography

## 🎨 Design Features

- CSS custom properties for consistent theming
- Smooth scroll animations
- Interactive navigation with dropdown menus
- Tabbed content on capabilities page
- Form validation with user feedback
- Scroll-to-top button
- Loading animation
- Card-based layouts

## 📱 Responsive Breakpoints

- Desktop: 1024px and above
- Tablet: 768px - 1023px
- Mobile: Below 768px

## 🚀 Getting Started

1. Clone or download the project
2. Open `index.html` in a web browser
3. For development, use a local server (e.g., Live Server in VS Code)
